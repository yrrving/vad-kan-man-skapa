# Vad kan man skapa?

Förslag på vad en besökare kan göra och ta med sig hem, ämne för ämne. Tre förslag per ämne: prova på, fördjupa och förverkliga. Den som läser kryssar i vad som går att genomföra på sin arbetsplats och skickar svaren med e-post.

Live: https://yrrving.github.io/vad-kan-man-skapa/

Sidan hämtar inget utifrån och sparar ingenting. Svaren skickas från besökarens eget mejlprogram.
